# Desarrollo local y pruebas

Este proyecto es un conjunto de landing pages en Astro para un dentista en CDMX.

## Requisitos
- Node.js 18+
- npm

## Instalación
```bash
npm install
npm run dev
```

## URLs de prueba
- http://localhost:5173/index-v1
- http://localhost:5173/index-v2
- http://localhost:5173/index-v3

## Notas
- Version Switcher en cabecera permite cambiar entre V1, V2, V3
- CTA WhatsApp visible sin scroll en móvil
- WCAG 2.2 AA y LFPDPPP compliance
