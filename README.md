# Dental Sonrisa Norte Landing

Landing pages para Dental Sonrisa Norte - 3 variantes (emocional, racional, local urgente) - Astro + Tailwind v4

## Variantes
- V1: Propuesta emocional (sin miedo, sin dolor)
- V2: Propuesta racional (experiencia, precios claros, reseñas)
- V3: Propuesta local urgente (ubicación, sábados, cercanía)

## Desarrollo local
```bash
npm install
npm run dev
```

Abre http://localhost:5173/index-v1, /index-v2, /index-v3
